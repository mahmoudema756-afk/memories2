# 📖 دليل تشغيل ونشر موقع "ذكريات" (Memories v2)

تطبيق ويب أنيق ونوستالجي لحفظ الذكريات في ألبومات صور مميزة مع ملاحظات ومواقف خاصة، مربوط بـ **Google Sheets** كقاعدة بيانات عبر **Google Apps Script**.

---

## 🎨 لوحة الألوان المعتمدة بالكامل (Strict Palette)
تم تصميم التنسيقات باستخدام 6 ألوان كلاسيكية دافئة حصرياً دون أي تدرجات نيون أو صارخة:

- **`#F5EFE3`**: كريمي دافئ — لون الخلفية الأساسي والمساحات.
- **`#3E3226`**: بني غامق — النص الأساسي والهياكل.
- **`#8B5E3C`**: بني قهوة — العناوين الرئيسية وأسماء الشخصيات.
- **`#C9A063`**: ذهبي باهت — الأزرار الرئيسية، الحدود برواز الصور البولارويد.
- **`#C98C7A`**: وردي غباري — بادجات التمييز، الوسوم، وأيقونات التفاعلات.
- **`#6E8B6E`**: أخضر زيتوني هادئ — مخصص حصرياً لإشارات وتنبيهات النجاح والتأكيد.

---

## 📁 هيكلية الملفات المنفصلة (Modular Architecture)
- **`index.html`**: هيكل الـ HTML النظيف (خالٍ من الأكواد المباشرة أو الروابط المكتوبة بنص صريح).
- **`style.css`**: جميع التنسيقات والمتغيرات اللونية واستجابة الشاشات (RTL).
- **`config.js`**: ملف إعدادات مستمر يحتوي متغير `CONFIG.webAppUrl`.
- **`api.js`**: محرك الاتصالات بـ Google Apps Script، ضغط الصور الآلي (Canvas)، وتشفير PIN.
- **`app.js`**: المنطق البرمجي للواجهة والتصفح وإدارة الألبومات والنوافذ.
- **`Code.gs`**: كود السيرفر لـ Google Apps Script لإدارة جدولي `Albums` و `Photos`.

## 🚀 خطوات النشر والربط بـ Google Sheets

1. **أنشئ شيت غوغل جديد**: افتح [Google Sheets](https://sheets.google.com) وقم بتسميته "ذكريات".
2. **افتح محرر السكربت**: من القائمة اختر **توسيعات (Extensions)** -> **Apps Script**.
3. **انقل الكود**: استبدل كود `Code.gs` بالكود الموجود في ملف [`Code.gs`](Code.gs).
4. **النشر (Deploy)**:
   - اضغط **نشر (Deploy)** -> **نشر جديد (New deployment)**.
   - اختر **تطبيق ويب (Web app)**.
   - **تنفيذ باسم**: `أنا (Me)`.
   - **من يتوفر له إمكانية الوصول**: `أي شخص (Anyone)`.
5. **نسخ الرابط**: انسخ رابط الـ Web App (ينتهي بـ `/exec`).
6. **الربط بالواجهة**:
   - يمكنك فتح ملف [`config.js`](config.js) ولصق الرابط في `webAppUrl`.
   - أو فتح `index.html` والضغط على زر **"ربط Google Sheets"** ولصق الرابط مباشرة.

## 🔒 حماية الرابط وتوضيح تقني هام (DevTools Visibility)

### 1. الرابط داخل كود الواجهة
رابط السيرفر غير ظاهر كمتغيّر أو نص في عناصر الـ HTML أو الواجهة المرئية إطلاقاً، بل يتم استدعاؤه عبر ملف `config.js` و `api.js`.

### 2. الحقيقة التقنية لظهور الرابط في Network Tab:
في أي موقع ويب ساكن (Static Client-Side Web App)، عندما يقوم المتصفح بإرسال طلب `fetch` إلى السيرفر، فإن أي شخص يفتح **أدوات المطورين (DevTools -> Network Tab)** يستطيع مشاهدة عنوان الـ URL للطلب الخارجي الموجه إلى Google Apps Script. **هذا قيد تقني أساسي في برمجة المتصفحات ولا يمكن منعه 100% بدون وجود سيرفر وسيط.**

### 3. خيار الـ Proxy المحسن (اخياري):
إذا كنت ترغب بإخفاء الرابط تماماً حتى عن Network Tab في DevTools:
- **الحل**: إنشاء سيرفر وسيط بسيط (Proxy) مثل **Cloudflare Worker** أو **Vercel Serverless Function**.
- **كيف يعمل**:
  1. المتصفح يرسل الطلب إلى رابط الوسيط: `https://my-proxy.workers.dev/api`.
  2. الـ Worker يتلقى الطلب ويقوم بإرساله من السيرفر خلف الكواليس إلى Google Apps Script.
  3. يظهر للمستخدم في Network Tab رابط الـ Worker فقط بدون رؤية رابط غوغل نهائياً.
- **تقييم المجهود**: يتطلب إنشاء حساب مجاني على Cloudflare أو Vercel وإضافة سكربت التوجيه (4-5 أسطر)، بينما الحل المباشر الحالي يعمل فوراً دون الحاجة لاستضافة إضافية.
